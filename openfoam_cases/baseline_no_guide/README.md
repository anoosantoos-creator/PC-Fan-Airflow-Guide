# Baseline OpenFOAM case

Measured fan frame and inactive hub, without guide vanes.

The tracked obstruction surface is a metre-scaled copy of
`cad_designs/fan_reference.stl`. Run `./Allrun` from an OpenFOAM 13
shell to mesh, solve, and sample the 100, 130, and 350 mm planes.

Case identifier: `baseline_no_guide`
